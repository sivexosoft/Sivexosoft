# SivexoSoft — Digital Solutions Agency

Premium dark-themed agency website. Static, no backend required.

## Stack
- HTML5, CSS3, vanilla JavaScript (ES6+)
- Three.js (background scene + hero 3D object)
- GSAP + ScrollTrigger
- Lenis smooth scroll
- Font Awesome, Google Fonts (Inter)

## Run locally
Just open `index.html` in a browser, or:

```bash
python3 -m http.server 8000
